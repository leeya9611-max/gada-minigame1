# A. 야리끼리 대소동 — 게임 사양·운영 정책서 v1 (2026-08-03)

> 대상: 개발 · 마케팅 · 운영 전원. **현재 배포본(gada-minigame1.vercel.app) 기준 확정 사양**입니다.
> 미확정 항목은 ⏳로 표시했습니다(결정되면 이 문서를 갱신하고 버전을 올립니다).

## 1. 이벤트 개요

- **형태**: 가다 앱 배너 → 웹뷰 러닝 미니게임. 한 달(4주) 챌린지, 주간 랭킹 리셋.
- **기간**: 2026-07-31(금) 시작 ~ 2026-08-27(목) 종료, 7일 × 4라운드
  - ⏳ 현재 소프트 오픈 일정(금~목 주기). 정식 런칭 시 월요일 시작으로 재설정 예정(설정 1줄 변경).
- **핵심 루프**: 안전교육(연습) 이수 → 무한 잔업 모드(랭킹전) → 일일 베스트 갱신 → 주간 랭킹 경쟁.

## 2. 게임 모드

| 모드 | 입장 조건 | 비용 | 랭킹 반영 | 특징 |
|---|---|---|---|---|
| 안전교육 | 없음 | 무료·무제한 | ✕ | 고정 코스(정류장 완주). HP 안 닳음, 잡히기 직전 2회 "봐주기" 후 3회째 교육 실패. 완주 시 무한 잔업 해금(계정당 1회, 서버 저장) |
| 무한 잔업 모드 | 안전교육 이수 | 티켓 1장/판 | ○ | 무한 러닝. 속도 점증, HP 0 또는 박소장에게 잡히면 종료 |

## 3. 조작 (좌우 대칭 — 한 손 플레이 가능)

- **화면 아무 곳 탭 = 점프** (공중에서 한 번 더 = 2단 점프)
- **아래로 45px 스와이프 = 슬라이드** — 누르고 있는 동안 계속 유지, 공중에서 하면 급강하 후 착지 슬라이드
- 데스크톱: Space/↑ 점프, ↓/S 슬라이드

## 4. 재화(티켓) 정책

지급·차감 **권위는 네이티브 앱/서버**. 웹은 표시와 요청만 한다(개발 중엔 로컬 스텁 동작).

| 획득 경로 | 수량 | 상태 |
|---|---|---|
| 최초 지급 | 2장 | ✅ (웹 로컬 기본값) |
| 광고 시청 | +1장 | ✅ 요청 송신(실제 광고·지급은 앱 연동 필요) |
| 출석 보상 | 1~6일차 +1장, 7일차 +3장 | ✅ (7일 순환, 하루 1회 서버 차단) |
| 친구 초대 | +1장 | ✅ 요청 송신(앱 처리 필요) |
| ⏳ 일일 자동 지급(2장, 자정 리셋·미사용 소멸) | — | **미구현·미확정** — 네이티브 담당 결정 필요 |

- 소비: 무한 잔업 입장/재도전 1장. 안전교육·재연습은 무료.

## 5. 점수·랭킹

- **판 점수(rankScore)** = 이동거리(10px당 1점) + 코인(개당 10점)
- **하루 점수 = 그날 최고 판(일일 베스트)** — 여러 판 해도 최고 1판만 인정
- **주간 점수 = 라운드(7일) 내 일일 베스트 합산** → 주간 랭킹(상위 50명 노출)
- 매 라운드 시작 시 주간 점수 리셋(후발 진입자도 경쟁 가능)
- 어뷰징 방어: 서버가 플레이 시간 대비 초당 130점 초과 점수 거부, 출석 중복은 DB가 차단
- ⏳ 월간(4주 합산) 랭킹 노출 여부 미확정 — 현재 주간만 표시

## 6. 티어 (주간 점수 기준, 순위와 무관한 개인 성취)

| 티어 | 기준(주간 점수) |
|---|---|
| 👑 야리끼리 마스터 | 6,000+ |
| 🦺 반장 | 3,000+ |
| 🔧 기공 | 1,000+ |
| 🧱 초보 조공 | 0+ |

## 7. 인게임 요소

- **HP**: 안전모 3개. 피격 시 1 감소 + 1.2초 무적 + 일시 감속. 0이 되면 "퇴근 실패"
- **추격**: 박소장과의 거리(gap)가 피격마다 크게 줄고, 무피격 주행으로 회복. 0이면 "덜미 잡힘"
- **장애물**: 지상 4종(점프 회피) + 2단 펜스 + 낮은 바(슬라이드 회피) + 낙하 투척물(마커 선행 경고) + 크레인 낙하물
- **아이템 4종**(가중치): 다방커피 30%·하트 20%(안전모 +1, 최대면 코인 3개로 대체), 부스터 30%(5초 무적·장애물 파괴), 자석 20%(5초 코인 흡인). 부스터·자석은 캐릭터 발밑에 남은 시간 게이지 표시
- **주차별 배경**: 1주 낮 → 2주 석양 → 3주 황혼 → 4주 야간(무한 잔업 전용)

## 8. 계정·닉네임

- 앱 진입: 딥링크 토큰(uid) = 가다 계정 기준. **토큰 없이 접속(내부 테스트)은 기기별 게스트 계정**(기기 로컬 수명 — 기기 바꾸면 기록 이어지지 않음)
- 닉네임: 2~10자, 한글·영문·숫자·공백. 금칙어 필터. 서버 중복 검사(중복 시 "이름2" 제안). 자동 생성 + 직접 입력. 변경 허용(⏳ 횟수 제한 정책 미정)
- 교육 이수·닉네임·점수·출석은 서버(Supabase) 저장 — 서버 재시작에도 유지

## 9. 보상 (⚠️ 대외 고지 금지 상태)

- **현재 세이프 모드**: 성적 연동 포인트 표시·포인트 교환 기능 숨김
- 사유: 게임산업법 28조(결과 연동 경품) 법적 검토 진행 중 — "참여→정액 포인트·추첨 / 순위→명예 보상" 구조로 변경될 가능성
- ⏳ 확정 필요: 보상 예산·층위(월간 top3 / 주간 top10 / 참여 추첨), 지급 주체·시점
