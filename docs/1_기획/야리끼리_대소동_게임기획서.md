## 3. 세계관

### 3.1 전체 세계관

배경은 대한민국 건설 현장과 퇴근길. "야리끼리(やりきり)"는 현장 은어로 **할당 작업량을 끝내면 조기 퇴근**하는 것. 근로자에게 야리끼리는 하루의 보상이자 로망이다. 이 게임은 그 로망을 방해하는 현장소장과의 유쾌한 추격극이다. 톤은 과장된 코믹·서민적 유머.

### 3.2 스토리 (시놉시스)

오후 3시 반. 김반장은 할당량을 끝냈다. "오늘도 야리끼리다!" 하고 정문으로 내달린다. 그러나 무한오더 박소장이 **바로 뒤에서 쫓아오며** 서류·도면 통·확성기를 던진다. 얻어맞으면 휘청여 속도가 줄고, 그 틈에 박소장이 바짝 붙는다. 김반장은 점프와 슬라이드로 장애물과 투척을 피하고, 다방커피로 기력을 회복하고, 퇴근길 부스터로 돌파하며 버스 정류장을 향해 달린다. 안전모가 다 벗겨지거나(HP 0) 박소장에게 덜미를 잡히면 잔업 확정.

## 5. Game System

### 5.1 기본 룰 (스테이지형)

김반장은 자동 전진, 유저는 점프·슬라이드 타이밍만 조절한다. 각 노선은 **정해진 길이의 스테이지**로, **시작 → 버스 정류장(집) 도착 = 완주 = 퇴근 성공**.

- **승리(완주)**: 박소장에게 잡히지 않고 정류장까지 도착. → 별점·보상·다음 노선 해금.
- **실패**: 도착 전에 **박소장에게 붙잡힘(gap 0)** 또는 **HP 0**.

**피격(지면 장애물 충돌·투척물 명중) 시:** HP −1 + **감속(느려짐) 패널티** + 박소장 추격 거리(gap) 감소. 피격 직후 1.2초 무적(깜빡임). 즉 한 번 맞으면 느려져 박소장이 바짝 붙는다 — **정류장까지 남은 거리 vs 박소장 거리**의 줄다리기가 핵심 긴장이다. 노선이 유한하므로 "조금만 더 버티면 완주"의 손에 땀 쥐는 마무리가 생긴다. 안전모 코인은 별점·점수용.

> 엔들리스(무한 거리)는 없앤 게 아니라, 전 노선 클리어 후 **랭킹 서브모드**로 유지(5.8).

### 5.2 노선(스테이지) 구성 & 난이도

**노선 = 유한 스테이지 5개**(맵 5종과 1:1, 5.15). 각 노선은 고정 길이(초기값 약 60~90초 러닝, 밸런싱 후 확정).

노선 내 난이도 곡선(공통 템플릿):

| 구간 | 위치 | 내용 |
|---|---|---|
| 도입 | 0~15% | 온보딩(투척 유예), 박소장 여유. 속도 낮음 |
| 본편 | 15~75% | 속도 램프(BASE 300→상승), 장애물·투척 등장 |
| 피날레 | 75~95% | **박소장 돌진(경고 후 급가속)** — 최고 난이도, "잡히기 직전" |
| 도착 | 95~100% | 정류장(집) 진입 → 박소장 따돌림, **완주** |

- **노선 번호가 오를수록** 기본 속도·장애물 밀도·투척 빈도·박소장 압박이 상향(1노선=쉬움 … 5노선=극한).
- 감속 디버프: 피격 시에만 일시 감속(예: 0.6배, 1.2초) → 박소장 접근.

### 5.2.1 별점 클리어 조건

완주 시 성과에 따라 별점(재도전·수집 동기):

| 별 | 조건(예, 노선별 튜닝) |
|---|---|
| ★ | 완주(정류장 도착) |
| ★★ | 무피격 or 코인 N개 이상 |
| ★★★ | 무피격 + 목표 코인 전부(or 목표 시간 내) |

별점은 다음 노선 해금·보상·랭킹에 반영.

### 5.3 Boss System (무한오더 박소장) — 추격 + 투척 [신규 강화]

박소장을 **화면 뒤편(좌측)에 상시 노출**한다. 추격은 거리(gap, px)로 관리한다.

| 요소 | 값(제안) | 설명 |
|---|---|---|
| 초기 추격 거리 | 180px | 게임 시작 시 여유 |
| 거리 상한 | 260px | 안전 주행으로 회복 가능한 최대 |
| 회복 속도 | +25 px/s | 안 맞고 달리면 서서히 벌어짐 |
| 피격 시 감소 | −70px | 맞을 때마다 확 좁혀짐 |
| 감속 연동 | 0.6배·1.2초 | 감속 중 박소장 상대 접근 가속 |
| 붙잡힘 | gap ≤ 0 | 즉시 실패 |
| **피날레 돌진** | 노선 75~95% | 경고 후 박소장 급가속 → gap 급감, 완주 직전 최대 긴장 |
| **정류장 도착** | 노선 끝 | 박소장 따돌림 = **완주 성공**(승리 연출) |

HUD에 추격 게이지 + **정류장까지 진행도 바**를 함께 노출해 "박소장 vs 남은 거리" 줄다리기를 시각화한다. 부스터(무적) 동안에는 gap도 회복. **완주(정류장 도착)로 추격이 닫히는 게 이 게임의 "결국?"에 대한 답이다.**

투척 규칙 [구현 `PROJECTILE`]:

| 항목 | 값 | 의미 |
|---|---|---|
| 경고 표시 | 1.6초 선행 '!' | 회피 창 보장 |
| 투척 속도 | 470 px/s | 낮을수록 여유 |
| 시작 유예 | 4초 | 온보딩 |
| 간격 | 6.5초 → 3.2초(60초에 걸쳐) | ±22% 무작위 |
| 상단/하단 비율 | 상단 30% | **상단=슬라이드로 회피 [신규]**, 하단=점프 |
| 높이 | 하단 8~42 / 상단 120~170 | 하단 점프, 상단 슬라이드 |

투척물: 결재 서류 뭉치(papers) / 현장 도면 통(tube) / 확성기(megaphone).

> 조작 대응 정리: 하단 투척·일반 장애물 = **점프**, 상단 투척·낮은 통과형 장애물 = **슬라이드**. 점프/슬라이드 2지선다가 핵심 재미.

### 5.4 재화 시스템

| 재화 | 획득 | 용도 |
|---|---|---|
| 안전모 코인 | 인게임(1개=랭크 10점) [구현] | 랭킹 점수 |
| 가다 포인트 | 결과값 기반 네이티브 지급 | 티켓 교환, **상점(캐릭터·아이템·맵)** 구매 |

랭크 점수 = 코인 × 10 + 이동거리 ÷ 10 [구현]. 웹앱은 계산·전달만, 지급·차감은 네이티브 API(개발명세서 2·5장).

### 5.5 티켓(입장권) 시스템

| 항목 | 값(초기) |
|---|---|
| 일일 무료 티켓 | 2장 |
| 광고 시청 | 1회당 1장 |
| 포인트 교환 | 10pt = 1장 |
| 친구 초대 | 1명당 1장 |

1 플레이 = 티켓 1장. 티켓 0 → 충전 화면(S5). 리텐션·바이럴 엔진.

### 5.6 아이템 시스템 [신규 개편]

| 아이템 | 효과 | 지속/수치 |
|---|---|---|
| 다방커피 | **안전모(HP) 1칸 회복** (최대 3), "각성" 연출 | 즉시 |
| 퇴근길 부스터 | 무적 + 장애물·투척 무시하며 돌진, gap 회복 | 5초 |

등장 주기 약 9~16초. 감속 효과는 아이템에서 제거(피격 패널티로 이동). HP가 이미 3이면 다방커피는 소량 점수/코인으로 대체 지급(낭비 방지, 튜닝). 상표권 회피: 창작 명칭만.

### 5.7 장애물 / 통과 요소

| 유형 | 예 | 대응 | 효과 |
|---|---|---|---|
| 지면 장애물 | 시멘트 웅덩이(puddle), 자재 더미(stack) [구현] | 점프 | 충돌 시 HP−1 + 감속 |
| **낮은 통과형 [신규]** | 파이프 구조물, 바리케이드, 비계 하부 | **슬라이드** | 점프하면 부딪힘, 슬라이드로 통과 |
| 상단 투척 [구현→회피 변경] | 확성기 등 높은 궤적 | **슬라이드** | 맞으면 HP−1 + 감속 |
| 하단 투척 | 서류·도면 낮은 궤적 | 점프 | 맞으면 HP−1 + 감속 |

소스: 지면/통과형 `assets/obstacles/industrial/`(타일셋+XML)에서 선별.

### 5.8 랭킹 시스템

서버 집계, 클라이언트 조회. 전국 / 연령대별(예: 50대) / 지역별(우리 동네) 3축.

- **노선별 랭킹**: 각 노선의 **클리어 타임·별점** 경쟁(스테이지형의 주 랭킹).
- **엔들리스 랭킹(서브모드)**: 전 노선 클리어 시 해금. 끝없이 달려 **최고 거리** 경쟁(주간 시즌 리셋). 점수 산식 5.4. 무한 러너를 좋아하는 유저·랭킹 경쟁·바이럴을 여기서 흡수.

### 5.9 티어 시스템 (확정: 직급 4단계)

랭크 점수 구간별 **직급 티어**. 현장 직급 서사와 밀착해 성취감을 준다.

| 티어 | 랭크 점수 | 콘셉트 |
|---|---|---|
| 초보 조공 | 0 ~ 999 | 갓 들어온 보조 인력 |
| 기공 | 1,000 ~ 2,999 | 기술을 익힌 숙련공 |
| 반장 | 3,000 ~ 5,999 | 팀을 이끄는 현장 반장 |
| 야리끼리 마스터 | 6,000 ~ | 칼퇴의 달인 |

[구현 동기화] `app/ranking/tier.ts`를 금속 5단계 → 직급 4단계로 교체(v2.2.1 반영). 티어 배지 아트는 직급 콘셉트로 제작.

### 5.10 상점 (아이템 · 캐릭터 · 맵)

포인트 소비처 통합 화면(S7). 구매·차감은 네이티브 API. 목적은 포인트 이코노미 순환.

- 소비 아이템: 박소장 방어권(피격 1회 무효), 시작 부스터 등.
- 캐릭터: 5.16.
- (노선 해금은 상점이 아니라 **이전 노선 클리어** 기반 — 5.15)

### 5.11 친구초대 / 바이럴

티켓 소진 후 친구 초대로 충전. 딥링크·카카오 공유. 초대 성공·어뷰징 방어 개발명세서 6장. K-factor 핵심.

### 5.12 리워드 / 재화 지급 연동

종료 시 결과값(JSON) 네이티브 전달 → 포인트 지급, 멱등키로 중복 방지(개발명세서 5장).

```json
{ "userId":"", "sessionId":"", "coinCount":0, "rankScore":0, "playDuration":0, "ticketUsed":1, "timestamp":"" }
```

### 5.13 이코노미 밸런싱

- 코인↔점수(1:10)·거리(÷10) [구현]. 포인트↔티켓(10pt=1장)·캐릭터/맵 가격은 포인트 이코노미 분석 후 확정.
- 티켓: 무료 2장으로 상위 랭킹은 어렵게 → 광고·초대·포인트 소비 유도.
- 캐릭터 특성은 밸런스 리스크 → 초기엔 코스메틱, 특성은 소폭·추후.

### 5.14 어뷰징 방어

- 점수/재화 서버·네이티브 권위. 클라 값 미신뢰.
- 결과값 검증(playDuration 대비 coinCount, 1판 상한, sessionId 재사용 차단; 4장).
- 초대 어뷰징 방어(자가·중복기기·명의; 6장).

### 5.15 노선(레벨) = 맵 5종

맵 5종이 곧 **노선(스테이지) 5개**다. 순서대로 난이도가 오르고, **이전 노선을 클리어(★ 이상)하면 다음 노선이 해금**된다(월드맵 S1.5).

| 노선 | 맵/콘셉트 | 난이도 | 변주 |
|---|---|---|---|
| 1노선 | 도심 재건축(낮 시가지) | 입문 | 표준, 온보딩 |
| 2노선 | 아파트 골조·비계 | 초급 | 낮은 통과형(슬라이드) 다수 |
| 3노선 | 지방 산업단지 | 중급 | 지면 장애물 밀도↑ |
| 4노선 | 야간 현장 | 상급 | 시야 좁음, 경고 '!' 중요도↑ |
| 5노선 | 지하 터널 공사 | 극한 | 상단 투척(슬라이드) 비중↑, 박소장 최강 |

각 노선은 고유 배경·장애물 구성·길이·박소장 세기를 가진다. 노선별 최고기록·별점·클리어 타임 저장.

### 5.16 캐릭터 상점 [신규]

포인트로 캐릭터를 구매·장착. 리텐션(수집)과 포인트 소비처.

| 캐릭터(예) | 콘셉트 | 특성(검토, 초기엔 코스메틱) |
|---|---|---|
| 김반장(기본) | 표준 | 없음 |
| 왕고참 조공 | 노련미 | 시작 HP +1 |
| 신입 청년 | 날렵함 | 점프력·슬라이드 회복 빠름 |
| 안전관리자 | 안전제일 | 피격 감속 시간 단축 |
| 여성 반장 | 다양성 | 코인 획득 소폭↑ |

특성은 밸런스 영향이 크므로 1차는 외형만, 특성은 소폭·별도 밸런싱 후 도입. 아트 소스: Kenney Toon Characters(남성/여성/로봇 등)로 프로토타입 가능.

## 10. 게임 출시 및 마케팅 계획 (BM)

### 10.1 비즈니스 모델

직접 과금 아닌 **리텐션·유입 실험**이 1차 목적. 재화는 무료(광고·초대·포인트).

| 축 | 내용 |
|---|---|
| 리텐션 | 일일 티켓, 랭킹 재도전, **캐릭터·맵 수집** |
| 신규 유입 | 친구초대 바이럴 |
| 포인트 순환 | 티켓·아이템·**캐릭터·맵** 소비처 |
| 광고 | 리워드 광고(티켓) |

### 11.3 용어
- 야리끼리: 할당량 끝내고 조기 퇴근하는 현장 은어.
- 노선(스테이지): 유한 길이의 레벨. 시작→정류장(집).
- 완주: 정류장(집) 도착 = 퇴근 성공 = 승리.
- 별점: 완주 성과 등급(★~★★★).
- HP(하트): 김반장 체력 3. 0이면 실패.
- gap(추격 거리): 박소장과의 거리. 0이면 붙잡힘(실패).
- 티켓: 1회 도전 입장권.
