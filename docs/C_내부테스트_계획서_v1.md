# C. 야리끼리 대소동 — 내부 테스트 계획서 + QA 체크리스트 v1 (2026-08-03)

> 대상: 내부 테스터 전원(개발·마케팅·운영). 소요 시간 1인당 약 20~30분.

## 1. 테스트 개요

- **목적**: ① 전체 플로우 무결성 ② 밸런스 체감(생존 60~120초 목표) ③ 기기별 성능·사운드 ④ 랭킹 정합
- **URL**: `https://gada-minigame1.vercel.app/game` (문제 발견 시엔 `?debug=1` 붙여 재현)
- **기간(안)**: 2일 (1일차 플로우·버그 / 2일차 밸런스·랭킹 경쟁)
- **참여 인원**: 제한 없음 — 많을수록 랭킹판 검증에 좋음

## 2. 계정 규칙 (중요 — 먼저 읽기)

- **1기기(브라우저) = 1계정.** 같은 폰이라도 크롬/사파리는 별도 계정.
- **시크릿 모드 금지** — 창 닫으면 계정 소멸.
- 기록은 기기 로컬 수명(테스트용 게스트) — 기기 바꾸면 처음부터. 정상입니다.
- 처음부터 다시 하고 싶으면: `?debug=1` → 좌하단 🐞 → **새 계정(로컬 초기화)** 버튼.
- 티켓 소진 시: 충전 화면 "광고 시청"(실제 광고 없이 +1 — 테스트 스텁) 또는 티켓 바의 ➕.

## 3. 기기 매트릭스 (역할 분담 권장)

| PC 브라우저 | 자유 | 키보드 조작 |

## 4. 시나리오 체크리스트

각 항목 통과 시 ✅. 실패하면 6장의 양식으로 리포트.

### A. 최초 진입 (새 계정 상태에서)
- [ ] 타이틀 → 퇴근 시작 → **닉네임 등록** 화면(자동 생성/다시 뽑기/직접 입력 동작)
- [ ] 이미 있는 닉네임 입력 시 "이름2" 식 대안 제시
- [ ] **출석 팝업** 자동 노출 → "1장 받기" → 티켓 +1, 팝업 닫힘
- [ ] 로비: 라운드 게이지(D-day·n/4), 티켓 바, ⚙설정, 나가기, 🎁출석(빨간 점 사라짐) 표시

### B. 안전교육
- [ ] 무한 잔업 카드가 잠금(🔒) 상태인지 → 교육 완주 후 해금되는지
- [ ] 튜토리얼 배너(점프→2단→투척→슬라이드) 순서대로 등장, 말풍선과 겹침 없음
- [ ] 안전모가 닳지 않는지, 잡히기 직전 "봐주기" 연출(2회) 후 3회째 교육 실패 화면
- [ ] 완주 시: 리본 배지 + "무한 잔업 모드 개방!" + 버스 도착 연출

### C. 무한 잔업 모드 (3판 이상)
- [ ] 입장 시 티켓 −1
- [ ] 탭=점프/2단, **아래 스와이프=슬라이드(홀드 유지)**, 점프 중 스와이프 → 급강하 슬라이드
- [ ] 아이템: 부스터/자석 획득 시 **발밑 게이지** 표시, 끝나기 1.5초 전 빨간 깜빡임
- [ ] 사망 2종 확인: 안전모 소진("퇴근 실패") / 박소장에게 잡힘("덜미 잡힘" — 정지·줌 연출)
- [ ] 결과 화면: 기록·코인·점수, 다시 도전(티켓 −1), 로비, 공유, 랭킹 버튼
- [ ] **생존 시간 기록**: 3판의 대략적 생존 초를 기록(5장 밸런스 설문)

### D. 랭킹
- [ ] 내 점수가 랭킹판에 닉네임과 함께 반영(일일 베스트 — 낮은 점수로 안 덮임)
- [ ] 같은 날 더 높은 점수 내면 갱신되는지
- [ ] 내 순위가 목록 안에 보이면 하단 고정 행이 없고, 목록 밖 순위면 골드 고정 행 표시
- [ ] 티어 배지가 주간 점수 기준으로 맞는지(1,000+ 기공 / 3,000+ 반장 / 6,000+ 마스터)

### E. 시스템
- [ ] ⚙설정: BGM/효과음 개별 토글 → 새로고침 후에도 유지
- [ ] iOS: **무음 스위치 켠 상태**에서도 효과음·BGM 재생
- [ ] 일시정지(우상단 ⏸) → 계속하기/포기/소리 설정. 홈 화면 갔다 오면 자동 일시정지
- [ ] 폰 세로로 들면 "가로로 돌려주세요" 안내, 가로로 돌리면 게임 복귀
- [ ] 이수 직후 결과 화면에서 바로 "무한 잔업 모드 가기" — 멈춤 없이 시작(과거 버그 재검)
- [ ] 출석: 같은 날 두 번째 수령 시도 → "내일 또 오세요" 비활성

## 5. 밸런스 설문 (플레이 후 1분)

1. 무한 잔업 평균 생존 시간: ① 30초 미만 ② 30~60초 ③ 1~2분 ④ 2분 이상
2. 난이도 체감: ① 너무 어려움 ② 적당 ③ 쉬움 — 어디서 주로 죽었나(장애물/투척물/잡힘)?
3. 스와이프 슬라이드: ① 잘 됨 ② 가끔 씹힘 ③ 어려움
4. 다시 하고 싶은가(5점 척도) + 한 줄 소감

## 7. 알려진 제약 (버그 아님)

- 게스트 계정은 기기 로컬 수명(정식 오픈 시 가다 계정 연동으로 해소)
- "광고 시청"이 광고 없이 즉시 +1 — 앱 연동 전 테스트 스텁
- 라운드가 금~목 주기(소프트 오픈 일정) — 정식 시작 시 월~일로 변경 예정
- 보상 관련 문구 없음 — 법적 검토 완료 전 의도적 비노출
- 네이티브 연동(웹뷰 닫기·실제 지급)은 앱 개발 빌드에서만 확인 가능
